# Simple Interactive Todo List (HTML/CSS/JS)

This is a simple, modern, and interactive todo list web app built with HTML, CSS, and JavaScript.

## Features
- Add new todo items
- Mark items as done using checkboxes
- Delete items from the list
- Responsive and clean design

## How to Use
1. Open `index.html` in your web browser.
2. Type a task in the input box and click "Add".
3. Use the checkbox to mark a task as completed.
4. Click the "Delete" button to remove a task.

## Files
- `index.html` — Main HTML file
- `style.css` — CSS for styling the app
